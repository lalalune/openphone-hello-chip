# Linux NPU ML Smoke

`hello-npu-ml-smoke` is the first Linux userspace proof that the booted system
can run a basic ML-shaped workload on the local NPU block.

## Scope

The smoke tool:

- opens `/dev/hello-npu`,
- rejects CPU-only fallback if the device node or ioctl path is missing,
- submits a fixed signed INT8 `2x2x3` GEMM tile through
  `HELLO_NPU_IOC_RUN_GEMM_S8`,
- reads counters through `HELLO_NPU_IOC_GET_COUNTERS`,
- checks `C = [[-44, 8], [139, -54]]`,
- prints hashes, counters, descriptor accounting, and PASS markers.

The matching Python runtime proof is generated by
`scripts/check_mvp_npu_ml_evidence.py --run` using the checked-in runtime
simulator and `golden_gemm_s8`.

## Target Usage

Enable the Buildroot package:

```sh
BR2_PACKAGE_HELLO_NPU_ML_SMOKE=y
```

After Linux boots with the OpenPhone hello NPU driver loaded:

```sh
hello-npu-ml-smoke
```

Expected success shape:

```text
openphone-evidence: target=linux artifact=hello_npu_ml_smoke
openphone-evidence: device=/dev/hello-npu
openphone-evidence: workload=gemm_s8_int8_2x2x3
hello-npu-ml-smoke: PASS workload=gemm_s8_int8_2x2x3 c=[[-44,8],[139,-54]] cycles=... macs=... ops=... errors=... unsupported_ops=...
openphone-evidence: status=PASS
```

Exit codes are stable for capture scripts:

| Code | Meaning |
| ---: | --- |
| `0` | GEMM completed and matched expected output |
| `2` | `/dev/hello-npu` missing or not openable |
| `3` | `HELLO_NPU_IOC_RUN_GEMM_S8` failed |
| `4` | GEMM output mismatch |

## Proof Boundary

This is Linux BSP and local runtime evidence only. It does not prove Android
NNAPI acceleration, TensorFlow Lite delegate execution, IREE lowering, DMA
writeback tensor execution, cache coherency, IOMMU isolation, phone-class TOPS,
power, thermal, or sustained throughput.

`scripts/check_hello_npu_linux_smoke.py` stays blocked until a real generated-AP
Linux transcript is captured at:

```text
docs/evidence/linux/openphone_hello_npu_ml_smoke.log
```

That transcript must contain the target markers above. Local source checks and
runtime simulator evidence are not allowed to claim integrated Linux+NPU proof.
